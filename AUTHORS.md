# Authorship and attribution

**MoheetBrain** originated the research questions, directs the independent programme and maintains the repository. Copyright © 2026 MoheetBrain and applicable contributors.

The project uses AI assistance for literature/source analysis, mathematical formulation, programming and editorial work. Original research documents identify Claude Code and distinguish founder questions, assistant proposals, established results and untested hypotheses. Those headers and distinctions are retained rather than converting all AI-assisted text into a claim of unaided authorship.

The institutional representation is a proposed research framework, not an established new scientific discovery. Clearing and maximum-circulation methods have prior art. ONS supplies the public calibration data and is credited separately. Cited authors and institutions are not project contributors or endorsers merely because their work is discussed.

Future human contributions should preserve accurate authorship in Git using an intentionally public identity; use a GitHub noreply email if desired. No contributor receives write or administrative access by making a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).
